# Project Morro: The Maybe-to-Magic Experience 🐾✨
> **HAX Baby Hackathon — Track 2: Your Own Baby (Original Character)**  
> *"Make the Work, Done Today"* — Supporting Slogan: *"Turn Maybe Into Done."*

---

## 🌟 Overview
**Project Morro** is a handcrafted, celestial, storybook portfolio website built for **Morro — The Little Star Prince**, an original magical creature created for Track 2 of the HAX Baby's First Website Hackathon.

The website presents a clean, joyful, and easy-to-understand experience focused directly on Morro's character, story, and inventions. When people repeatedly postpone tasks, they release a cloudy signal called a **"Maybe"**. Morro catches this energy in his enchanted pouch, transmutes it into an actionable micro-step, and helps creators take one tiny, comfortable step today.

---

## 🧭 Simplified User Journey & Architecture

The website follows an intuitive, clutter-free storybook progression:

1. **Hero — Meet Morro**:
   - Original character artwork with 3D pointer parallax and floating spirit companion **Sparky**.
   - Clear headline (*"Turn Maybe Into Done."*) and original tagline (*"Make the Work, Done Today"*).
   - Clean CTAs (*"Catch Your Maybe"* and *"Meet Morro"*).
2. **Character Sheet — Official 5-Point Dossier**:
   - 1. Name: Morro (The Little Star Prince).
   - 2. What they are: Rare magical SHiko born from the stars (fox ears, golden-tipped dragon horns, white & blue fur).
   - 3. What they do: Postponement Transmuter & Celestial Encourager.
   - 4. Their story: Postponed dreams in the cosmos gathered and ignited into star birth.
   - 5. Tagline: *"Make the Work, Done Today"*.
3. **Origin Story — 4 Visual Scenes**:
   - Short, illustrated visual progression (&lt;150 words per scene): *Tomorrow Again*, *The Maybe Storm*, *The Birth of Morro*, and *A New Purpose*.
4. **The Maybe-to-Magic Ritual — Central Signature Interaction**:
   - The visitor enters a postponed task (or selects a sample prompt).
   - Clicks **"Catch the Maybe"** → particle absorption animation into Morro's pouch with cheerful audio sweep.
   - Morro displays a gentle positive reminder and suggests **one achievable first step**.
   - Visitor can **"Copy First Step"** or click **"I'm Ready to Start!"** to trigger starlight celebration confetti and fanfare.
5. **Morro's Inventions — Three Portfolio Case Studies**:
   - **Project 1: The Maybe Catcher** (Postponement energy transmuter with direct link to experience the ritual).
   - **Project 2: Star Sprint Engine** (Fictional case study for a lightweight focus timer with visual dial preview and working Case Study modal).
   - **Project 3: The Done Constellation** (Fictional case study for milestone sky charting with compact constellation graphic and working Case Study modal).
6. **Compact Footer with Visible Credits**:
   - Full visible attribution for character art, Web Audio API synthesis, fonts, and icons.

## 🏆 Standout Features & Immersion

- **Tier 1 Immersion**:
  - 3D mathematical pointer tracking on desktop + touch responsive bobbing on mobile.
  - Celestial Day / Cosmic Night theme toggle shifting palettes and ambient lighting.
  - Web Audio synthesizer with a prominent, accessible **Mute/Unmute switch** in the header.
- **Tier 2 Standout**:
  - **Nightlight / Flashlight Dream Cursor**: An ambient radial starlight beam that follows the cursor in Cosmic Night mode, illuminating background dream layers.
- **Hidden Easter Egg**:
  - Tapping **Sparky the Spirit Companion** 3 times unlocks **Morro & Sparky's Midnight Tea Party & Cosmic Blessing** modal with secret lore and a custom music-box lullaby.

## 💻 Running Locally

```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Run production build
npm run build

# Run linter
npm run lint
```
